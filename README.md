# Manas Mishra - Portfolio Website

Welcome to the source code of my personal portfolio website. This project showcases my experience, skills, and projects as a Full Stack AI & Agentic Developer.

## 🚀 Live Demo
[Visit Portfolio](https://mmishracode.github.io/)

## 🛠️ Built With
- **HTML5 & CSS3**: Semantic structure and modern styling.
- **JavaScript**: Interactive elements and dynamic content.
- **Agentic Workflows**: Demonstrations of AI-powered automation (Customer Onboarding, Sales Automation, Lead Gen).
- **Responsive Design**: Optimized for all devices.

## 📂 Project Structure
- `index.html`: Main entry point containing the single-page layout.
- `styles.css`: Custom CSS for styling, animations, and layout.
- `scripts.js`: Logic for mobile menu, smooth scrolling, and agentic workflow simulations.
- `imgs/`: Directory containing project assets and icons.

## ✨ Features
- **Hero Section**: Introduction and resume download.
- **Skills Grid**: Categorized technical expertise.
- **Experience Timeline**: Detailed professional history.
- **Agentic Workflows**: Interactive demos of AI agents.
- **Project Showcase**: Highlights of key projects with case studies.
